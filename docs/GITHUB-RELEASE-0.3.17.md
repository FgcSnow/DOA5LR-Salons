# DOA5LR-Salons 0.3.17 — Lab (Destroyed) removed (online desyncs and crashes)

**Everyone should update: download `DOA5LR-Salons-Installer.exe` below and open it (close the game first).** It only downloads what changed (a few MB when your stage files are intact). The other files are used by the installer automatically.

## Why

- The little surprise of 0.3.16, **Lab (Destroyed)** as the second variant of the Lab tile, is **removed**. It caused desyncs online, and a crash of players and spectators in rooms (`game.exe+433D69`, in the game's stage sound code) appeared only with 0.3.16.
- **As long as one player in your room still has 0.3.16, they can still pick it and everyone in the room loads it:** please update and ask your room to update too.

## Changes

- The update deletes `DOA5LR-LabDestroyed.asi` and its log. The Lab tile is the original one again.
- ExtraStages and the stage-select pictures are back to the 0.3.16 build made before that work (every tile keeps its own correct picture). Every other file is byte-identical to 0.3.16 (same Installer 1.3.11, no stage data download).
