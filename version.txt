note=0.3.7: the installer is back (1.0.3), as a separate download on the release page (never inside the zip: if an antivirus quarantines it, the zip must not go with it). We found what antivirus behavioral engines disliked (Kaspersky killed the install and rolled it back): a hidden command shell the installer used to replace itself on self-update. Gone. Retested clean on Kaspersky; Defender detections were cloud-ML false positives, reported to Microsoft (and Kaspersky). All our binaries are now signed; sources on GitHub.
note=0.3.7: the installer now checks that every required file is present (at start, after each install and when the game closes) and warns you if one is missing (antivirus quarantine): restore it, add the game folder to the antivirus exclusions, click REINSTALL. Do not play with a partial pack.
note=0.3.7: WiFi-Wired-Detector 0.8.7 shows only the wired/Wi-Fi tag next to names; the ping display added in 0.8.6 is removed.
note=If your antivirus flags anything from this pack, please report it as a false positive (Microsoft: microsoft.com/wdsi/filesubmission, Kaspersky: opentip.kaspersky.com) - every report helps.
note=0.3.6: 60fps-menus 0.13c is completely inactive online. With 0.3.5, rooms of 3-4 players still got round-start network errors and a character select mismatch. Now, as soon as you enter the Online menu, the plugin does nothing at all; offline everything stays at 60 fps.
note=HOTFIX (0.3.5): with pack 0.3.3/0.3.4, some online matches (2-player rooms in our tests) dropped with a network error right after the intros: the 60fps plugin did not recognise that kind of online match, took the intro for an offline cutscene and ran it at 60 fps without the 30 Hz stream pairing -> desync. 60fps-menus 0.13b fixes it: in those matches the intros stay native, everything else is unchanged. Please update.
note=0.3.4: character select grid, names and button hints no longer disappear while a player picks a costume (old root d3d9.dll removed; AutoLink, costumes and desktop resolution unchanged). 60fps-menus: win poses after an OFFLINE fight at 60 fps.
note=Reminder: the installer updates everything in one click and keeps a backup; the game opens it after you close it when a newer pack exists. The pack sends nothing anywhere and our plugins write no log files (only Lobby 0.9.0 keeps its local DOA5LR-Lobby.log diagnostic, see LOBBY-EN.txt).
